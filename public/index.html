Docs & contoh

File diunggah sekali langsung ke Blob via presigned URL, lalu disajikan lewat /file/<filename>. Semua format didukung, maks 25 MB.

Contoh curl (presigned)

RESP=$(curl -s -X POST https://svazer-upload.vercel.app/api/request-upload \
  -H 'Content-Type: application/json' \
  -d '{"fileName":"foto.jpg","fileType":"image/jpeg"}')

curl -X PUT "$(echo "$RESP" | jq -r .uploadUrl)" \
  -H 'Content-Type: image/jpeg' --data-binary @foto.jpg

echo "https://svazer-upload.vercel.app/file/$(echo "$RESP" | jq -r .filename)"

Contoh Node

import fs from 'fs';

const { uploadUrl, filename } = await (await fetch('https://svazer-upload.vercel.app/api/request-upload', {
  method: 'POST', headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ fileName: 'foto.jpg', fileType: 'image/jpeg' })
})).json();

await fetch(uploadUrl, { method: 'PUT', headers: { 'Content-Type': 'image/jpeg' }, body: fs.readFileSync('foto.jpg') });
console.log('https://svazer-upload.vercel.app/file/' + filename);

Endpoint

  • POST /api/request-upload — minta presigned URL
  • PUT {uploadUrl} — upload langsung ke Blob
  • GET /file/:filename — ambil file (proxy)
